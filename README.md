## 二、仓库简介

本仓库是《人机协同与 AI 编程》课程的个人作品集**主仓库**，用于按周存放全学期的实验代码、实验报告、运行截图与项目成果。

- 每一周的实验内容统一放在对应的 `weekXX-*` 目录中；
- 每周目录下的 `README.md` 是当周实验的记录模板；
- 所有提交历史（Commit）都保留了每周的学习轨迹，方便老师查阅与个人复盘。

## 五、使用方法（写给未来的自己）

完成每周实验后，在仓库根目录依次执行下面几条命令即可把成果同步到 GitHub：

```bash
# 1. 查看当前有哪些文件发生了改动
git status

# 2. 把改动加入“暂存区”
git add .

# 3. 提交并写清楚这次做了什么（示例）
git commit -m "week02: 完成 Python 基础练习"

# 4. 推送到 GitHub 远程仓库
git push
```
